# Privacy Policy — YouTube Layout: Video fijo + Comentarios

Last updated: 2026-08-20

This extension does not collect, store, transmit, or share any
personal data, browsing history, or user content.

## What it does

The extension runs entirely on `https://www.youtube.com/*` pages. It
only reads and rearranges elements already present in the YouTube
watch page's DOM (the comments section and the video player column)
and applies CSS to change their layout. No information is sent off
the device, to the developer, or to any third party.

## Data collection

- No personal data is collected.
- No analytics, tracking, or advertising code is included.
- No network requests are made by the extension.
- No data is stored, other than what Chrome itself may cache locally
  to run the extension (no `storage` permission is used).

## Permissions

The extension only uses a content script scoped to
`https://www.youtube.com/*`. This is required so the script can find
and reposition the video and comments elements on that page. No other
host or permission is requested.
